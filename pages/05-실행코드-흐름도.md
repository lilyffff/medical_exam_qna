# 실행 코드 전체 흐름도

## 중학생을 위한 한 장짜리 코드 지도

```mermaid
flowchart TD
    RAW["의료 원문 JSON<br/>교과서·QA·가이드라인"]
    BUILD_DB["build_rag_index.py<br/>긴 글을 작은 조각으로 나눔"]
    DB[("rag_index.sqlite3<br/>글자 검색 도서관")]
    BUILD_VEC["build_embedding_index.py<br/>전문 자료를 골라 벡터 준비"]
    EMB_MODEL["embedding_model.py<br/>문장의 뜻을 숫자로 바꿈"]
    VEC[("임베딩 3개 파일<br/>의미 좌표·문서번호·이름표")]

    STUDENT["학생<br/>PC·휴대폰 브라우저"]
    APP["app.py<br/>화면·출제·채점·안전검사 담당"]
    QUIZ["KorMedMCQA<br/>4개 직종 시험 문제"]
    REQUEST["문제 + 정답 보기"]
    RAG["local_rag.py<br/>글자 검색과 의미 검색을 합침"]
    TOP4["관련 근거 최대 4개"]
    GUARD1{"검색 근거가<br/>정답을 충분히 지지하는가?"}
    MEDIKO["MediKo<br/>근거만 사용해 해설 작성"]
    GUARD2{"정답 번호·가짜 출처·<br/>새 수치·진료 지시 검사"}
    RESULT["학생 화면<br/>정답·해설·근거·안전 고지"]
    SAFE["생성 중단<br/>정답과 검색 원문만 표시"]

    RAW --> BUILD_DB --> DB
    DB --> BUILD_VEC --> EMB_MODEL --> VEC
    QUIZ --> APP
    STUDENT --> APP --> REQUEST --> RAG
    DB --> RAG
    EMB_MODEL --> RAG
    VEC --> RAG --> TOP4 --> GUARD1
    GUARD1 -- "부족" --> SAFE --> RESULT
    GUARD1 -- "충분" --> MEDIKO --> GUARD2
    GUARD2 -- "실패" --> SAFE
    GUARD2 -- "통과" --> RESULT --> STUDENT
```

다섯 실행 파일은 서로 경쟁하는 프로그램이 아니라, **자료 만들기 팀**과 **문제 풀이 팀**으로 역할을 나눕니다.

- 자료 만들기 팀: `build_rag_index.py` → `build_embedding_index.py` → `embedding_model.py`
- 문제 풀이 팀: `app.py` → `local_rag.py` → `embedding_model.py`
