# 의료 원문 `*.json` 해설집

## 무엇인가요?

`medical_knowledge_data/` 아래의 JSON은 교과서·전문 QA·가이드라인·논문 내용을 컴퓨터가 항목별로 읽을 수 있게 저장한 원천 자료입니다. JSON은 **항목 이름이 붙은 디지털 학습 카드**와 같습니다.

전문 QA는 주로 다음 정보를 가집니다.

```json
{
  "domain": "의학 분야",
  "question": "전문 질문",
  "answer": "전문 답변"
}
```

원천 문서는 주로 다음 형태입니다.

```json
{
  "domain": "의학 분야",
  "content": "교과서나 가이드라인의 본문"
}
```

`build_rag_index.py`가 이 차이를 구분해 QA는 질문과 답변을 합치고, 원천 문서는 `content`를 사용합니다. 원본 JSON은 수정하지 않고 읽기만 합니다.

## 안전한 실습

파일 수 확인:

```powershell
(Get-ChildItem -LiteralPath "medical_knowledge_data" -Filter "*.json" -File -Recurse).Count
```

임의 파일의 키 이름만 확인하며 의료 원문 전체를 출력하지 않습니다.

```powershell
python -c "import json,pathlib; p=next(pathlib.Path('medical_knowledge_data').rglob('*.json')); d=json.loads(p.read_text(encoding='utf-8-sig')); print(p); print(sorted(d.keys()))"
```

의료 원문은 이용 조건과 개인정보·저작권을 확인하고, 공개 GitHub에 올리지 않습니다.
