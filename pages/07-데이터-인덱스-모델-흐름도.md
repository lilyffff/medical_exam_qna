# 데이터·인덱스·모델 파일 전체 흐름도

## 중학생을 위한 한 장짜리 파일 지도

```mermaid
flowchart TD
    RAW["의료 원문 *.json<br/>내용이 담긴 원래 교재"]
    CONCEPT["medical_concepts.json<br/>동의어·관련 개념 사전"]
    DB[("rag_index.sqlite3<br/>99,742개 문서 조각과<br/>빠른 글자 찾아보기")]
    VEC[("rag_embeddings.npy<br/>22,508개 문서 × 384개<br/>의미 좌표 성적표")]
    IDS[("rag_embedding_ids.npy<br/>벡터 행과 DB 문서 ID를<br/>연결하는 학번표")]
    META["rag_embeddings.meta.json<br/>모델·개수·차원·DB 크기를 적은<br/>제품 설명서"]

    QUESTION["문제 + 정답 보기"]
    EXPAND["개념 사전으로<br/>검색어 확장"]
    WORD["SQLite에서<br/>글자가 겹치는 문서 검색"]
    MEANING["질문을 384개 숫자로 바꾸고<br/>문서 의미 좌표와 비교"]
    JOIN["ID로 의미 검색 결과의<br/>원문·출처를 SQLite에서 찾음"]
    RANK["글자 순위 + 의미 순위를 합쳐<br/>최종 근거 4개 선택"]
    ANSWER["MediKo가 근거 안에서만<br/>시험 해설 작성"]

    OLD_CFG["adapter_config.json<br/>GPT-Neo LoRA 조립 설명서"]
    OLD_WEIGHT["adapter_model.safetensors<br/>과거 Medical QA 보충 가중치"]
    OLD_TOKEN["tokenizer.json<br/>GPT-Neo 문장 분해 사전"]
    UNUSED["현재는 보관만 함<br/>MediKo와 연결하지 않음"]

    RAW -->|"조각내어 저장"| DB
    RAW -->|"고품질 자료 선별 후 E5 변환"| VEC
    DB -->|"documents.id 기록"| IDS
    DB -->|"파일 크기 기록"| META
    VEC -->|"모양·모델 정보 기록"| META

    QUESTION --> EXPAND
    CONCEPT --> EXPAND
    EXPAND --> WORD
    EXPAND --> MEANING
    DB --> WORD
    VEC --> MEANING
    IDS --> JOIN
    MEANING --> JOIN
    DB --> JOIN
    WORD --> RANK
    JOIN --> RANK --> ANSWER

    OLD_CFG --> UNUSED
    OLD_WEIGHT --> UNUSED
    OLD_TOKEN --> UNUSED

    classDef active fill:#e8f5e9,stroke:#2e7d32,color:#173d20;
    classDef data fill:#e3f2fd,stroke:#1565c0,color:#102a43;
    classDef old fill:#eeeeee,stroke:#757575,color:#444,stroke-dasharray:5 5;
    class DB,VEC,IDS,META,RAW,CONCEPT data;
    class QUESTION,EXPAND,WORD,MEANING,JOIN,RANK,ANSWER active;
    class OLD_CFG,OLD_WEIGHT,OLD_TOKEN,UNUSED old;
```

핵심은 `rag_embeddings.npy`만으로는 원문을 읽을 수 없다는 점입니다. `rag_embedding_ids.npy`가 학번을 알려 주고, `rag_index.sqlite3`가 실제 문장과 출처를 돌려줍니다. `rag_embeddings.meta.json`은 이 세 파일이 같은 세트인지 검사합니다.
