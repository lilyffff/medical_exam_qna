# `rag_embeddings.npy` 해설집

## 무엇인가요?

22,508개 의료 문서의 뜻을 각각 384개 숫자로 바꿔 저장한 NumPy 배열입니다.

```text
모양: (22508, 384)
자료형: float32
```

학교에서 학생 22,508명에게 국어·수학처럼 384개의 특징 점수를 붙인 큰 성적표라고 생각할 수 있습니다. 질문도 같은 384개 숫자로 바꾼 뒤 방향이 비슷한 문서를 찾습니다.

## 왜 정규화하나요?

각 행의 길이를 1로 맞춥니다. 문장이 길어서 숫자가 커지는 영향을 줄이고 의미 방향을 공정하게 비교하기 위해서입니다.

## 실습

전체를 RAM에 복사하지 않고 읽습니다.

```powershell
python -c "import numpy as np; a=np.load('rag_embeddings.npy',mmap_mode='r'); print(a.shape,a.dtype); print(float((a[0]**2).sum()))"
```

마지막 값이 1에 가까우면 벡터가 정규화된 것입니다.
