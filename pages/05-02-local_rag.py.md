# `local_rag.py` 코드 해설집

## 한 문장으로 설명

`local_rag.py`는 질문과 정답을 보고 도서관에서 관련 책을 찾듯, SQLite 글자 검색과 임베딩 의미 검색을 합쳐 근거 4개를 고르는 **의료 자료 사서**입니다.

## 전문용어와 일상용어

| 전문용어 | 쉬운 뜻 | 학교생활 비유 |
|---|---|---|
| RAG | 자료를 먼저 찾고 그 자료로 답하기 | 교과서 페이지를 찾고 서술형 답 쓰기 |
| 정규화 | 글자 모양을 일정하게 정리 | 이름표 표기를 한 형식으로 통일 |
| 형태소 분석 | 문장을 의미 있는 낱말로 나누기 | 문장에서 주어·동사·명사 찾기 |
| FTS5 | 긴 글에서 단어를 빠르게 찾는 SQLite 기능 | 도서관 책 뒤의 찾아보기 |
| BM25 | 검색어가 중요한 문서를 앞에 두는 점수 | 여러 검색 결과의 관련성 순위 |
| 임베딩 | 문장의 뜻을 숫자 묶음으로 표현 | 친구 취향을 여러 점수로 나타내기 |
| 코사인 유사도 | 두 숫자 방향이 얼마나 비슷한지 | 두 학생의 과목별 점수 모양 비교 |
| RRF | 서로 다른 두 순위를 합치는 공식 | 두 심사위원 순위를 합쳐 최종 순위 결정 |
| 메모리 매핑 | 큰 파일을 필요한 부분만 읽기 | 두꺼운 사전을 통째로 복사하지 않고 필요한 쪽만 펼치기 |

## 처리 순서

1. 환경변수로 SQLite, 임베딩, 개념 사전 경로를 정합니다.
2. HTML 문자·유니코드·공백·숫자 단위를 정리합니다.
3. `medical_concepts.json`으로 관련 동의어와 병태생리를 추가합니다.
4. Kiwi와 정규식으로 중요한 검색어를 뽑습니다.
5. SQLite FTS5에서 글자가 겹치는 후보를 찾습니다.
6. E5 임베딩으로 의미가 비슷한 후보를 찾습니다.
7. RRF로 두 순위를 합치고 같은 원본의 중복을 없앱니다.
8. 상위 4개에 검색 방식·일치어·점수·출처를 붙입니다.

## 함수 지도

### 경로와 정규화: 39~105행

- `knowledge_path()`, `index_path()` 등은 `.env` 또는 기본 경로를 돌려줍니다.
- `normalize_medical_text()`는 `&#x20;`, 대소문자, 여러 공백과 `250 mL` 표기를 정리합니다.
- `expand_medical_query()`는 충분한 단서가 있을 때만 개념을 확장해 과잉 검색을 줄입니다.

### 검색어 만들기: 108~162행

- `_kiwi()`는 Kiwi가 설치됐을 때만 사용하고 실패하면 정규식으로 대신합니다.
- `query_terms()`는 흔한 단어, 숫자, 단위를 빼고 핵심어를 최대 18개 만듭니다.
- 복합 의학용어는 분해된 말과 원형을 함께 보존합니다.

### 글자 검색: 168~203행

`_fts_candidates()`는 핵심어를 `OR`로 연결해 넓게 찾고, 긴 용어는 개별 검색도 하여 흔한 단어에 밀리지 않게 합니다.

### 의미 검색: 205~281행

- `_embedding_index()`는 세 임베딩 파일과 SQLite 크기가 서로 맞는지 검사합니다.
- 맞지 않으면 오류로 앱을 멈추지 않고 FTS 검색만 사용합니다.
- `_semantic_candidates()`는 질문 벡터와 문서 벡터의 내적을 계산합니다. 벡터가 정규화되어 있어 이 값은 코사인 유사도와 같습니다.

### 최종 결합: 288~383행

- `search_medical_knowledge()`는 FTS와 의미 검색을 동시에 준비합니다.
- FTS 순위는 `1/(60+순위)`, 의미 순위는 `1.2/(60+순위)`를 더합니다.
- 의미 검색에 약간 더 큰 1.2 가중치를 줍니다.
- 같은 `source_path`는 한 번만 사용하고 최대 4개를 반환합니다.
- `format_sources()`는 `[근거 1]` 형태의 읽기 쉬운 글로 바꿉니다.

## 직접 해 보는 실습

### 실습 1: 문장 정리

```powershell
python -c "from local_rag import normalize_medical_text; print(normalize_medical_text('&#x20; 소변량 250 mL'))"
```

### 실습 2: 개념 확장

```powershell
python -c "from local_rag import expand_medical_query; print(expand_medical_query('복강내출혈 외상 환자의 소변량 감소'))"
```

### 실습 3: 실제 검색

```powershell
python -c "from local_rag import search_medical_knowledge; r=search_medical_knowledge('폐결핵 공기주의 격리'); print([(x['source_name'],x['matched_terms'],x['semantic_score']) for x in r])"
```

## 기억할 점

검색 점수가 높다는 것은 비슷하다는 뜻이지 의학적으로 무조건 참이라는 뜻은 아닙니다. 그래서 `app.py`의 가드레일과 사용자의 출처 확인이 필요합니다.
